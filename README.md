# Ecommerce-Customer-Churn-Analysis---HB
Understanding and analyzing why customers are leaving an ecommerce company.

Ecommerce Customer Churn Analysis
Welcome to my Customer Churn Analysis project. I tackled this project to grow my SQL knowledge and learn to navigate databases. The goal was to analyze the data, understand customer behaviors, and provide insight and recommendations to reduce churn rates. The analysis is based on a dataset containing various customer attributes and behaviors. This repository also contains the queries I ran to get my results.

Project Approach
I got this dataset from Kaggle, and it contains a lot of different customer information. I used SQL to clean, explore, and analyze this dataset. This analysis has several sections: Data Cleaning, Data Exploration, Analysis and Insights, and Recommendations. This is just the readme, the actual overview and analysis is in the Customer Churn Overview & Analysis pdf. Below I explain what each attribute found in the dataset means:

Attributes Explained
CustomerID: a unique ID for each customer
Churn: a value of 1 or 0 based on whether a customer (1 = churned, stayed = 0)
Tenure: how long a customer has/had been with the company (in months)
PreferredLoginDevice: what device a customer typically uses
CityTier: a value from 1 to 3 based on the type of city a customer lives in (1 = major metro, 2 = mid-size city, 3 = small city)
WarehouseToHome: Distance from the nearest warehouse to a customer’s home (in km)
PreferredPaymentMode: what payment method a customer typically uses
Gender: a customer’s gender
HourSpendOnApp: how many hours a week a customer spends on the app
NumberOfDeviceRegistered: how many devices a customer has registered to their account
PreferredOrderCat: what category a customer typically buys from
SatisfactionScore: a value from 1 to 5 chosen by a customer based on their satisfaction
MaritalStatus: a customer’s marital status
NumberOfAddress: how many addresses a customer has saved
Complain: a value of 1 or 0 based on whether a customer has filed a complaint (1 = yes, 0 = no)
OrderAmountHikeFromLastYear: increase in a customer’s order amount compared to last year
CouponUsed: how many coupons a customer has used
OrderCount: how many orders a customer has made
DaySinceLastOrder: how many days since a customer’s last order
CashbackAmount: cashback a customer has received
